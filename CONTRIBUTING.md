# Contributing to JobTrack

Thank you for your interest in contributing to JobTrack!

## How to contribute

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Test your changes.
6. Commit your changes.
7. Push your branch.
8. Open a Pull Request.

## Contribution ideas

- Add support for new company career pages.
- Improve job detection and filtering.
- Fix bugs.
- Improve the dashboard UI.
- Optimize scanner performance.
- Add new features.

Please create an issue before making major changes so we can discuss the idea.

Thank you for helping improve JobTrack!
